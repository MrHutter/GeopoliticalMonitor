# Security Policy

## Supported versions

Only the latest commit on the `main` branch is supported. Security fixes are not backported to earlier commits.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting: open this repository's **Security** tab and select **Report a vulnerability**.

Do not open public issues, pull requests or discussions for vulnerabilities.

Include enough detail to reproduce the problem, such as the affected commit, the steps to reproduce, and the expected and observed behavior.

## Response expectations

Geopolitical Monitor is a personal, early-stage desktop application. Reports are reviewed on a best-effort basis, and there is no guaranteed response or fix time.
